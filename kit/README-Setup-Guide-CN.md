# 📱 CallGuard《免手接》定制落地方案（荣耀 Magic6 至尊版 / MagicOS 8.0–9.0）

## 一、 先打开手机自带隐藏的「动嘴接电话 + 自动免提」
- **设置路径**：`设置 → 荣耀AI & YOYO → YOYO助理（或智慧语音） → 通话场景设置 → 开启「来电/去电语音控制」`
- **接听口令**：来电响铃时，不用喊“你好YOYO”，直接清晰说：「接听电话」（系统自动接通并强制打开免提扬声器）
- **拒接口令**：来电响铃不想接时，直接说：「挂断电话」
- **通话中为什么说话挂不断？**
  荣耀官方底层限制：电话一旦接通，麦克风即被通话独占，YOYO 语音助手强制闭麦（防止聊天提到“挂断”二字误挂电话），因此通话中喊“挂断电话”不会有反应。
- **通话中免手挂断解法**：
  1. 原生最快解法：进「电话 App → 右上角三个点设置 → 高级 → 开启【按电源键结束通话】」，手湿或满手油时用手背/指关节轻顶一下侧边电源键即可秒挂。
  2. 完全免碰解法：导入下方生成的 CallGuard 自动化宏，通话中【隔空遮挡顶部距离传感器 2 秒】或【手肘轻碰桌面让手机晃动】即可自动挂断并恢复原音量。
  3. 隔空手势补充：进「设置 → 荣耀AI & YOYO → 智慧感知 → 隔空手势 / 注视屏幕减弱来电铃声」一并开启。

## 二、 亲情白名单自动免提配置参数（防外卖/推销/诈骗电话自动外放）
- **适用场景**：做饭/洗碗/开车/修车满手油污免手接听
- **已绑定亲情白名单号码（共 2 个）**：`13800138000`、`13900139000`
- **已绑定微信亲情备注名**：`爸`、`妈`、`老婆`、`老公`
- **自动接听延迟**：响铃 **3 秒** 后自动接通并强制切换为 **扬声器免提（音量 90%）**
- **通话中免触挂断动作**：**摇晃手机 2 下（或手肘轻磕桌面）自动挂断**
- **非白名单陌生号策略**：**陌生号码保持正常响铃，绝不自动接通外放**

## 三、 3 分钟导入步骤
1. **安卓手机（荣耀 / 华为 / 小米 / OPPO / vivo）**：
   - 安装免费自动化工具 **MacroDroid**（或 **Tasker**），双击导入随包生成的 `family-whitelist-auto-speaker.macro`。
   - 打开手机「设置 → 辅助功能（无障碍） → 已安装的服务 → 开启 MacroDroid」，并在多任务界面下拉把 MacroDroid **加锁**（电池设为「无限制」）。
2. **苹果 iPhone（iOS 17 / iOS 18）**：
   - 进入「设置 → 专注模式 → 右上角 + 号新建【亲情免手模式】 → 允许通知的联系人仅勾选：爸、妈、老婆、老公」。
   - 进入「设置 → 辅助功能 → 触控 → 音频通话方式 → 选【扬声器】」，同页面进入「自动接听通话 → 开启并设为 3 秒」。
   - 进入「设置 → 辅助功能 → 语音控制 → 开启」，通话完毕直接说 **“轻点结束通话”** 即可动嘴挂断！
